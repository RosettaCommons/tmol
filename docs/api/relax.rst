Relax
=====

FastRelax alternates packing and minimization under a configurable weight
schedule. :func:`tmol.fast_relax` is imported from the top-level package and
documented in :doc:`top_level` together with its two minimizers,
:class:`tmol.CartesianRelaxMinimizer` and :class:`tmol.KinematicRelaxMinimizer`;
:mod:`tmol.relax` also exports the default schedule and the ``RelaxMinimizer``
protocol for custom minimizers.
