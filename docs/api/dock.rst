Docking
-------

Ligand docking: a genetic-algorithm search over a ligand's placement, its
torsions, and optionally pocket sidechains, scored on a precomputed receptor
grid. :func:`tmol.dock.run_docking` is the entry point; see
:doc:`/workflows/ligand_docking` for the workflow.
